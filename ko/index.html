로봇 제어 시스템 연구실 (ROCOS)

복잡한 시스템을 이해하고,
지능적인 움직임을 구현합니다.

ROCOS는 제어 시스템, 이동 로봇, 자율주행, 데이터 기반 모델링을 연결하여 역동적인 환경에서 인지하고, 추정하고, 판단하며 행동하는 지능형 시스템을 연구합니다.

ROCOS와 함께 연구할 학부생과 대학원생을 환영합니다. 연구 참여에 관심이 있다면 Bongsu Hahn 교수에게 문의해 주세요 →.

연구 철학

Bongsu Hahn 교수의 연구는 신뢰할 수 있는 지능이 물리적 이해, 피드백, 추정, 데이터의 세심한 통합에서 비롯되어야 한다는 관점에 기반합니다. 엄밀한 시스템 수준의 사고를 실제 공학 문제와 연결하고, 모델 기반 방법과 데이터 기반 접근법을 각각의 강점이 가장 잘 발휘되는 방식으로 결합하고자 합니다. 연구 전반에서 해석 가능성, 강인성, 실험적 검증을 중시하며, 복잡하고 변화하는 환경에서도 신뢰성을 유지하는 지능형 시스템의 구현을 지향합니다.
