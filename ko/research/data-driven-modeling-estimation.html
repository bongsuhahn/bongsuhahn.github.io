02 / 연구 · 분야 04

데이터 기반 모델링 및 추정

연구 분야 개요

데이터 기반 모델링 및 추정은 측정 데이터와 수학적 모델을 연결하여 숨겨진 상태를 추정하고 시스템 거동을 이해하는 분야입니다.

I / 궁극적 목표

연구가 지향하는 방향

측정 데이터에서 의미 있는 구조를 찾아 복잡한 동적 시스템의 모델링, 추정, 모니터링, 이해에 활용합니다.

II / 핵심 연구 질문

연구를 이끄는 질문

  1. 제한된 측정값으로 숨겨진 상태나 파라미터를 어떻게 추론할 수 있을까요?

  2. 정보성을 유지하면서도 계산 효율적인 모델을 어떻게 구성할 수 있을까요?

  3. 데이터 기반 방법은 물리적 이해를 어떻게 보완할 수 있을까요?

III / 연구 방법론

이해에서 검증까지

  1. 측정 데이터
  2. 모델 구성
  3. 상태 및 파라미터 추정
  4. 검증
  5. 해석

IV / 연구 철학

연구의 바탕이 되는 관점

데이터는 개별 관측값으로만 다루기보다 구조, 동역학, 물리적 통찰과 결합할 때 가장 큰 가치를 발휘합니다.

V / 대표 응용 분야

연구의 적용 분야

  • 상태 추정
  • 시스템 식별
  • 고장 진단
  • 배터리 모니터링
  • 물리 지식 기반 모델링

VI / 방법 및 도구

연구에 활용하는 방법

  • 칼만 필터링
  • 비선형 상태공간 모델링
  • Koopman 기반 모델링
  • 파라미터 추정
  • 해석 가능한 데이터 기반 학습

VII / 연구 분야 간 연계

연계 연구 분야

데이터 기반 모델링 및 추정은 강인 제어, 자율주행, 지능형 로봇을 지원하는 추론 기반을 제공합니다.

제어 시스템이동 로봇자율주행데이터 기반 모델링 및 추정현재 분야
