02 / 연구 · 분야 04

데이터 기반 모델링 및 추정

분야 개요

측정 데이터와 동역학 모델을 결합하여 직접 관측하기 어려운 상태와 파라미터를 추정하고, 모델의 가관측성과 불확실성을 분석합니다.

동역학 모델링 · 상태·파라미터 추정 · 가관측성

데이터 → 동역학 모델 → 추정 → 해석

I / 궁극적 목표

연구가 지향하는 목표

측정 정보로 뒷받침될 수 있는 동역학 모델을 구성하고, 그 내부 표현을 의미 있게 해석·추정하며, 변화하는 운전 조건에서도 신뢰성 있게 활용할 수 있는 방법론을 구축합니다.

II / 핵심 연구 질문

연구를 이끄는 질문

  1. 데이터 기반 모델은 무엇을 표현해야 하는가?

    주어진 측정 정보가 실제로 뒷받침할 수 있는 동역학적 복잡도는 어느 정도이며, 이를 바탕으로 모델의 구조와 차수를 어떻게 결정해야 하는가?

  2. 측정 데이터로부터 실제로 무엇을 추론할 수 있는가?

    입출력 데이터로부터 어떤 잠재 상태와 파라미터를 구별하고 신뢰성 있게 추정할 수 있으며, 어떤 상태 방향은 측정 정보로 충분히 뒷받침되지 않는가?

  3. 물리적 구조와 데이터를 어떻게 결합해야 하는가?

    물리적 구조를 학습에 활용하면서도, 학습된 잠재 변수를 충분한 근거 없이 특정 물리 상태와 일대일 대응시키지 않으려면 모델을 어떻게 구성해야 하는가?

  4. 운전 조건이 달라질 때 모델은 무엇을 적응시켜야 하는가?

    시스템이 학습 조건에서 벗어날 때 모델 전체를 다시 학습하기보다 어떤 동역학 구조는 유지하고, 어떤 저차원 요소를 적응시켜야 하는가?

  5. 학습 조건 밖에서도 모델을 얼마나 신뢰할 수 있는가?

    운전 프로토콜, 운전 조건, 데이터셋이 달라질 때 예측 성능뿐 아니라 잠재 상태의 해석과 불확실성의 신뢰성도 함께 유지되는가?

III / 방법론적 접근

측정에서 해석 가능한 추정까지.

먼저 측정된 입출력 거동을 바탕으로 동역학 모델을 구성하되, 모델의 복잡도는 예측 성능뿐 아니라 측정 정보가 실제로 뒷받침할 수 있는 범위를 함께 고려하여 결정합니다. 후보 상태 표현에 대해 가관측성, 민감도, 상태 간 구별 가능성, 추정 성능을 분석하여 측정으로 충분히 뒷받침되지 않는 방향을 식별하고 모델 구조를 정제합니다. 이후 상태 및 파라미터 추정을 통해 직접 측정하기 어려운 내부 정보를 복원하고, 운전 조건에 따라 잔여 동역학이 달라지는 경우에는 저차원의 적응 구조를 도입합니다. 최종적으로는 동일 조건에서의 정확도뿐 아니라 서로 다른 프로토콜, 데이터셋, 운전 조건에서도 모델의 성능과 해석, 불확실성이 얼마나 유지되는지를 평가합니다.

  4. 상태·파라미터 추정
  5. 운전 조건 간 검증
