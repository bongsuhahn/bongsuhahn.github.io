02 / 연구 · 분야 01

제어 시스템

분야 개요

ROCOS의 제어 시스템 연구는 제한된 센싱과 불확실성, 외란, 모델 불일치가 존재하는 실제 시스템에서 물리 모델과 추정 상태, 시스템 정보를 신뢰할 수 있는 제어 입력으로 연결하는 방법을 다룹니다. 제어를 단순한 제어기 설계 문제로 보기보다, 시스템 동역학과 측정 정보, 상태 추정, 폐루프 거동이 어떻게 연결되는지를 함께 고려합니다. 이를 통해 실제 공학 시스템에서 해석 가능하고 강인하며 실험적으로 검증할 수 있는 제어 방법을 연구합니다.

I / 궁극적 목표

연구가 지향하는 목표

물리적으로 의미 있는 모델과 추정 정보를 활용하여 센싱 제약, 외란, 불확실성, 운전 조건의 변화 속에서도 원하는 시스템 거동을 안정적으로 유지할 수 있는 제어 방법론을 구축합니다.

II / 핵심 연구 질문

연구를 이끄는 질문

  1. 제어를 위해 시스템 동역학을 어떻게 표현해야 하는가?

    불필요한 복잡도를 늘리지 않으면서 실제 제어에 필요한 시스템 거동을 충분히 표현하려면 어떤 동역학 요소를 모델에 포함해야 하는가?

  2. 직접 측정하기 어려운 물리량을 제어에 어떻게 활용할 것인가?

    상태, 힘, 토크, 외란과 같이 직접 측정하기 어려운 물리량을 어떻게 신뢰성 있게 추정하고 실제 제어 판단에 활용할 것인가?

  3. 불확실성과 모델 불일치에 어떻게 대응할 것인가?

    외란, 파라미터 변화, 미모델링 동역학, 운전 조건 변화로 실제 시스템이 기준 모델과 달라질 때에도 어떻게 신뢰할 수 있는 제어 성능을 유지할 것인가?

  4. 모델 기반 방법과 데이터 기반 정보를 어떻게 결합할 것인가?

    물리 모델과 데이터로부터 얻은 정보를 각각 신뢰할 수 있는 영역에서 활용하면서, 해석 가능성과 시스템 수준의 일관성을 유지하려면 어떻게 결합해야 하는가?

III / 방법론적 접근

시스템 동역학에서 폐루프 검증까지.

먼저 폐루프 제어에 필요한 시스템 동역학과 상태 정보를 중심으로 제어 지향 모델을 구성하고, 실제로 측정하거나 추정해야 하는 물리량을 정의합니다. 직접 센싱이 어렵거나 비효율적인 경우에는 상태, 외란, 힘, 토크 등의 추정기를 활용합니다. 이후 불확실성, 외란, 파라미터 변화, 잔여 모델 불일치를 명시적으로 고려하여 제어기를 구성하고, 필요한 경우 물리적 구조를 유지하면서 적응 기법이나 데이터 기반 보정을 결합합니다. 최종적으로 모델 정확도 자체보다 폐루프 성능과 실제 실험을 통해 제어 방법의 유효성을 검증합니다.

  1. 제어 지향 모델링
  2. 상태·외란 추정
  3. 강인·적응 제어
  4. 폐루프 성능 평가
  5. 실험 검증

주요 연구 주제

  • 제어를 위한 상태 및 외란 추정
  • 센서리스 힘·토크 추정
  • 제한된 센싱 환경에서의 강인 제어
  • 모델 불일치를 고려한 적응 제어
  • 모델 기반 및 데이터 기반 정보의 제어 활용
  • 충돌 및 상호작용을 고려한 제어
  • 폐루프 실험 검증
