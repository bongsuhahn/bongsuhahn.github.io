02 / 연구 · 분야 02

이동 로봇

분야 개요

ROCOS의 이동 로봇 연구는 센싱이 제한되고 환경과의 물리적 상호작용이 이상적이지 않은 상황에서 로봇의 운동을 어떻게 모델링하고 추정하며 제어할 것인지를 다룹니다. 이동 로봇을 이상적인 기구학 시스템으로 단순화하기보다 구동 한계, 바퀴와 지면의 상호작용, 슬립, 외란, 운동 추정 오차와 같은 실제적인 요소를 이동 문제의 일부로 함께 고려합니다. 이러한 로봇 중심의 관점에서 탑재 센싱과 운동 추정을 실제로 실행 가능한 제어와 연결하고, 상위 자율주행 알고리즘이 신뢰할 수 있는 물리적 이동 기반을 구축하고자 합니다.

I / 궁극적 목표

연구가 지향하는 목표

제한된 센싱과 외란, 슬립, 비이상적인 환경 상호작용 속에서도 로봇의 물리적 상태를 추정하고 예측 가능한 움직임을 구현할 수 있는 신뢰성 있는 이동 기반을 구축합니다.

II / 핵심 연구 질문

연구를 이끄는 질문

  1. 이동 로봇의 실제 운동을 어떻게 모델링해야 하는가?

    불필요한 복잡도를 증가시키지 않으면서 실제 로봇의 운동 특성과 구동 제약을 충분히 설명하려면 어떤 수준의 기구학과 동역학을 모델에 포함해야 하는가?

  2. 탑재 센서만으로 로봇은 무엇을 추정할 수 있는가?

    직접 측정할 수 있는 정보가 제한된 상황에서 로봇의 속도와 운동 상태, 슬립, 외란을 어떻게 신뢰성 있게 추정할 수 있는가?

  3. 명령한 움직임과 실제 움직임의 차이에 어떻게 대응할 것인가?

    바퀴–지면 상호작용, 외란, 구동 특성, 모델 오차로 인해 실제 로봇의 움직임이 명령한 움직임과 달라질 때 이를 어떻게 추정하고 제어에서 보상할 것인가?

  4. 운용 조건이 달라져도 이동 성능을 어떻게 유지할 것인가?

    속도와 주행 동작, 노면 상태, 하중, 물리적 상호작용이 달라질 때에도 운동 모델과 제어의 신뢰성을 어떻게 유지할 것인가?

III / 방법론적 접근

센싱에서 강인한 이동까지.

먼저 로봇의 실제 형상과 구동 한계, 센서 구성에 기반하여 운동 모델을 구성합니다. 이후 탑재 센서의 측정 정보를 이용해 운동 상태를 추정하고, 슬립이나 외란, 모델 불일치로 인해 발생하는 실제 움직임의 편차를 분석합니다. 이러한 추정과 보상 구조를 이동 제어와 결합하여 비이상적인 조건에서도 명령한 움직임을 물리적으로 실현할 수 있도록 합니다. 최종적으로 다양한 주행 동작과 운용 조건에서 추정된 운동, 제어 명령, 실제 로봇 거동 사이의 일관성을 중심으로 성능을 검증합니다.

  1. 로봇 운동 모델링
  2. 탑재 센싱
  3. 운동 상태 추정
  4. 이동 제어 및 보상
  5. 실제 로봇 검증
